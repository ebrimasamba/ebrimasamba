A fintech wallet platform enabling digital payments, transfers, and financial services.

**Features**

- Bank-to-wallet transfers
- Secure KYC verification
- Mobile payment infrastructure
- Savings & financial tools

---

### 🚗 Rideshare Platform

An Uber-like ridesharing application designed for **West African markets**.

**Features**

- Real-time location tracking
- Ride matching system
- Mobile payments
